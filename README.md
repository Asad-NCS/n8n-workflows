## ⚡ How to Use

1. Download or clone this repository.
2. Open n8n.
3. Go to **Workflows → Import → JSON** and select the workflow file from `workflows/`.
4. Modify any nodes or credentials as needed.

---

## 📝 Notes

- Exported workflows are compatible with n8n **v2.x+**.  
- Sensitive credentials are **not included**; you must configure them locally.  
- Images are for reference only.
